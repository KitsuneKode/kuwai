## Proximity: a disagreement, settled as a setting

The island session prefers "touch the top edge (+8 px slop)". This session
added `services/Pointer.qml` + `IslandBar` `wantsProximity / inZone /
zoneHits`, because the user asked for 30–60 px. Why it doesn't have the
feared costs:

- **No click stealing**: it asks Hyprland for `j/cursorpos` over the request
  socket; there's no input region, so a browser tab under the zone keeps
  every click.
- **False positives**: two samples in a row inside the zone (≈160 ms at
  12 Hz) and not moving faster than 2500 px/s; 20 px slack on the way out,
  then the same 450 ms fold. It only reveals (no grow) like the edge strip.
- **Cost**: socket requests at 4 Hz (12 Hz in the top 140 px band), only
  while the island is minimal/tucked and not hovered.

`Settings.islandProximity` (default on, the user's request) turns it off,
leaving only the edge. Untested with real pointer motion: use ydotool as in
your notes.

## Built here (commits d1a84a1, ae99bd2 and earlier)

- **Screensaver** (`modules/screensaver`): comes on after
  `screensaverMins` idle minutes while Caffeine is on (`screensaverWhen`:
  caffeine · always · off), never over fullscreen. Styles
  (`screensaverStyle`): **dusk** (default; `DuskScene.qml`, an original
  evening scene drawn live, no video), **live** (the live wallpaper on one
  screen, Dusk on the rest), **still**. Any input dismisses and is
  swallowed. `rice screensaver [start|stop]` (not show/hide: `qs ipc … show`
  is the CLI's own listing).
- **Performance fix for the screensaver lag**: it used to decode the video
  on every screen while the live wallpaper decoded the same file underneath,
  and load the still at full size uncached. Now: one decoder at most,
  `services/Saver.showing` pauses the live wallpaper, still decoded at
  ≤1080p and cached. (The heat/lag the user saw was mostly `llama-server`:
  ~300% CPU, 14 GB, the assistant's local model.)
- **Live wallpaper** (`modules/wallpaper/LiveWallpaper.qml`): built only
  while on; pauses when windows cover ~85% of a screen, fullscreen, locked,
  on battery (`liveOnBattery`), under the screensaver.
- **Wallpaper picker: Live tab** (`ThemePanel.qml`): stills from `rice-wall
  json` (cached in `~/.cache/rice/live-thumbs`), "Off" first, the big preview
  plays the selection muted after 250 ms. Not yet looked at on screen.
- **`bin/rice-wall`**: `add FILE [NAME] [--no-loop]` (seamless loop, ≤1440p,
  30 fps, NVENC), `import` (Wallpaper Engine *video* items from a Workshop
  folder, if Steam is ever installed), `list`, `play`, `off`, `json`.
- **Mini notch**: the time centred symmetrically (`miniSide/miniCore`);
  your commit 4c1bc93 carried that hunk, which is fine.
- **Updates**: the watchdog runs whenever a run is shown (a feed that ended
  without "done" left the island saying "updating" forever).
