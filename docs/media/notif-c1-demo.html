C1 notifications — why click still opened the browser

Root cause: the live shell was running from ~/.local/share/kuwai/shell (stable), not your repo. Edits under ~/Projects/rice/shell do nothing until you switch channel or promote.

1 · Run the code you edited

rice channel dev          # run shell from the repo
rice restart              # or: bin/rice-shell

# confirm:
pgrep -af 'qs -p .*/shell'

You should see qs -p …/Projects/rice/shell (or your dev root), not .local/share/kuwai.

When you are happy: rice promote copies the repo into stable (after rice-check).
