# Keyboard lighting for kuwai themes

kuwai does not control external RGB keyboard firmware (the only keyboard light it touches is a laptop's `rgb:kbd_backlight` when dimming on idle). If you want to match an external RGB keyboard manually to one of kuwai's 13 themes, use saturated LED colours at low night brightness (~40%) — pastel UI accents wash out to white on RGB diodes, and pure blue/violet reads brighter when nudged slightly toward cyan or magenta.

| Theme | Island accent | Suggested LED colour | Nearest preset |
| --- | --- | --- | --- |
| Kuwai Night | `#66c7ff` | `#3d7bff` or cool white | blue / white |
| Aurora | `#5eead4` | `#00ffc8` | aqua / green |
| Chrome Sunset | `#ff3fb0` | `#ff1fa8` (secondary `#00d9ff`) | pink / magenta |
| Crimson Noir | `#ff4d6a` | `#ff0a3c` | red |
| Deep Field | `#a48bff` | `#7c4dff` | indigo / violet |
| Earthlight | `#ffad4a` | `#ff8c00` | warm amber |
| Garage | `#ff5a3c` | `#ff3b00` | red / orange |
| Matcha | `#8fe3a2` | `#39ff7a` | green |
| Neon District | `#3ee6ff` | `#00e5ff` (secondary `#ff2fd0`) | cyan |
| Pixel Dusk | `#ffb86b` | `#ff9500` | amber / orange |
| Sakura Night | `#f5a9c8` | `#ff2f92` | pink |
| Violet Hour | `#b48cff` | `#a040ff` | purple |
| Void | `#8ab4ff` | `#1a8cff` | blue |
