## 1. Live Bugs, Weirdnesses, and State-Machine Risks

1. **Login runtime `TypeError` + stuck auth ring (`shell/modules/lock/GreeterView.qml:108,110,236`)**:
   - `GreeterView` calls `focusGrab.grab()` on `Component.onCompleted`, but `FocusGrabber.qml:14` defines `function arm()`, not `grab()`. It throws at login startup and only works accidentally via `onTargetChanged`.
   - At line `236`, `SequentialAnimation on opacity` resets `parent.opacity = 1`, which resolves to `avatar` instead of the pulsing border `Rectangle`, leaving the ring stuck at mid-pulse opacity after auth finishes.
2. **Fail-closed permanent notification mute/redaction (`shell/services/Notifs.qml:43-50,275`)**:
   - `muted: dnd || dndMute || !shareKnown` and `sharing: !shareKnown || dndMute`. A `1000ms` timer retries `kuwai.privacy_resync()` 5 times (`shareSyncTries < 5`). If Hyprland is still settling or IPC hiccups during those 5 seconds, `shareKnown` remains `false` permanently, muting and redacting every notification until shell restart.
3. **Moments sticky lifetime collapse (`shell/services/Moments.qml:58-82,136-145`)**:
   - `onHeldChanged` (line `82`) mutates `hide.interval = Math.min(hide.interval, 2000)`, so hovering and leaving a `600000ms` (10-minute) sticky agent moment shrinks its lifetime to **2 seconds**.
   - `dropCard()` (line `144`) never resets `cardHeld`.
4. **Settings race before initial load (`shell/config/Settings.qml:20-26,119-166`)**:
   - Calling `Settings.set()` while `readBusy === true` bumps `generation` ahead of `readGeneration`, causing `loadedFile()` (line `133`) to skip `accept(text)` and leave `root.document = {}` until reload.
5. **Implicit boolean/timer clusters**:
   - `IslandBar.qml:64-354`: 13 interacting booleans + 9 timers per monitor (`win.pushed` stays stuck while the pointer remains over the notch; `nearDwell` and `intent` self-retrigger indefinitely in `edgeOnly`).
   - `ClipboardPanel.qml:58-708`: Overlay `mode` is unified, but window lifecycle still runs on 8 flags + 6 timers (`onSetupChanged` and `onOpenChanged` both clobber shared `armed`).
   - `Osd.qml:128-362`: 9 separate settle/debounce timers racing during USB DAC hotplugs.
6. **Six dead v0.2.0 primitives (0 production instantiations)**:
   - `PanelFrame.qml`, `Material.qml`, `BlurShape.qml`, `ContentSwap.qml`, `Pressable.qml`, and `StateView.qml` (plus `EmptyState.qml`, only imported by `StateView`) were shipped in `0.2.0` with **zero** call sites in `shell/modules/`.
   - `FocusGrabber.qml` is only used in `GreeterView.qml` (with the broken `.grab()` call); 5 overlay windows still hand-roll `HyprlandFocusGrab` + `160–180ms` arming timers.
   - `ListRow.qml` is adopted in only **4 / 18** island panels; 3 menu systems coexist (`ui/ContextMenu`, legacy `ActionMenu`, `TrayMenu`); 4 callers still import `RaisedButton` directly instead of `ui/Button`; `SweepPanel.qml:259` and `AssistantOverlay.qml:534` use `ScrollFade` without `ScrollHint`.
7. **Hyprland namespace mismatch & missing `dim_around` (`hypr/kuwai/rules.lua:135-155`)**:
   - `xray-default` excludes `kuwai-.*` (hyphen), while `kuwai.screensaver`, `kuwai.saver-film`, `kuwai.fade`, `kuwai.wallpaper`, `kuwai.wallfx`, `kuwai.scrim` use a **dot** (`kuwai.`), accidentally inheriting `xray = true`.
   - `kuwai-center` has no `dim_around` rule despite `docs/DESIGN.md:92` specifying it.
   - `jb-popup-size` (`rules.lua:119`) forces `min_size = monitor_w*0.5 monitor_h*0.5` on every untitled floating JetBrains popup (including tiny hover/autocomplete popups).
8. **Stale worktrees & `rice-*` leftovers**:
   - 11 extra git worktrees remain checked out (including 5 detached-HEAD audit trees from `2026-11-18` and 4 T3 trees under `Depot/`).
   - `systemd/kuwai-backup.*` and `system/kuwai-wake.*` still use `"Rice:"` descriptions; `bin/__pycache__/` holds 10 stale `rice*.pyc` files; `shell/services/Alarms.qml:121` still probes `/var/lib/rice-wake/at`.

## 2. Highest-ROI Performance, Memory, and Battery Gains

1. **Continuous 60–200 Hz `FrameAnimation` in `shell/components/FluidHighlight.qml:45-48`**:
   - Used in **11** panels/views. `FrameAnimation { running: h.target !== null; onTriggered: h.follow() }` runs every compositor frame (200 Hz on the Acer) calling `mapToItem()` even while completely stationary. Replacing with geometry/scroll signals drops idle panel wakeups to `0`.
2. **20 Hz PipeWire peak monitor + 50 ms timer running while hidden/locked (`shell/modules/island/IslandRest.qml:823,835-843`)**:
   - Missing `!Saver.showing && !Saver.locked && !Saver.screensOff && rest.visible && !Theme.reduceMotion`, keeping PipeWire peak capture and 20 Hz QML updates alive while locked, fullscreen, or under screensaver.
3. **Infinite 30 s `pgrep` + failed `Qt.createComponent` loop (`shell/modules/voxtype/VoxtypeHost.qml:45-127`)**:
   - On any machine without voxtype, `probe` runs every 30 s forever, spawning `pgrep` and logging 3 failed component loads.
4. **Unbounded `Clipboard` `times.tsv` & triple `wl-paste` watcher (`shell/services/Clipboard.qml:275`, `bin/kuwai-clip:148`, `systemd/kuwai-clipboard.service:13`)**:
   - `times.tsv` grows forever without pruning and is re-parsed in full on every copy; `kuwai-clipboard.service` runs 3 `wl-paste` daemons and forks bash + `sleep 0.4` + `cliphist list` on every copy; `$cache/edit/clip-*.ext` files are never cleaned.
5. **Remaining periodic polling loops**:
   - `Updates.qml:107-128`: spawns `sh -c stat` every 120 s (replace with `FileView` `watchChanges` on `/var/lib/pacman/local`).
   - `Alerts.qml:119-148`: runs **two** full `ps -eo ... --sort=-rss` `/proc` scans back-to-back every 60 s (or every 10 s under memory pressure).
   - `Screensaver.qml:312`: ticks every `1000ms` to display `HH:MM` (align to the minute like `LockView.qml:38`).
6. **Avoidable boot RAM (~3.5+ GB headroom)**:
   - `voxtype` fp32 CPU model (`3,123 MB` → int8 or lazy-load on first dictation key-down).
   - `hypr/kuwai/startup.lua:42-44` still launches `nm-applet --indicator` (~40 MB) despite kuwai's native `WifiList.qml`, and calls `hyprctl setcursor` twice (`lines 10, 48`).
   - `kuwai-feeds.service` (~45 MB) starts unconditionally even when neither Gmail nor `gh` is configured; `Limits.qml:238` keeps `kuwai-usage --watch` running even with no T3/Devin accounts.

## 4. Security & Portability Rough Edges

1. **Screen-share privacy gap (`hypr/kuwai/automation.lua:8`)**: `kuwai-island` (clipboard shelf) and `kuwai-assistant` are omitted from `K.privacy.layers` (`no_screen_share = true`), unlike `kuwai-notifs`, `kuwai-center`, and `kuwai-auth`.
2. **Root helper file-mode race (`bin/kuwai-update-root:45,159`)**: Set `os.umask(0o077)` at startup and open `/run/kuwai-update-root.out` with `O_NOFOLLOW | 0o600` so `.kuwai-bak` backups of `/etc` files are never briefly world-readable.
3. **Plaintext bearer token (`bin/kuwai-usage:66`)**: Migrate `t3-token` from plaintext `$XDG_STATE_HOME/kuwai/t3-token` to `secret-tool` (matching `bin/kuwai-feeds:506`).
4. **Lua quoting edge case (`shell/services/Agents.qml:93-94`)**: A window class ending in `]` produces `]]]` inside `[[class:...]]`; whitelist `[A-Za-z0-9._-]` like `Notifs.qml:851`.
5. **Hardcoded personal defaults**:
   - `hypr/kuwai/automation.lua:194`: Personal GPS coordinates (`27.2353, 94.1053`) hardcoded as Night Light default.

   - `bin/kuwai-shazam:22`: Hardcoded personal USB DAC (`Audiocular_D07`) fallback; `Osd.qml:337` hardcoded headphone model regex; `LauncherPanel.qml:339` stale HyDE error copy.
