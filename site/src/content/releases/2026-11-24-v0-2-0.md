- **Standalone Look engine:** Atomic single-writer palette switching with WCAG contrast enforcement, custom templates, user hooks, and 11 bundled themes with zero external theme framework requirement.
- **Zero token drift:** Every size, duration, and color across the shell resolves from one shared token table, verified automatically before every release.
- **Automated visual checks:** Every panel is rendered and checked across standard and 200% text scales (141 frames, 0 failures) before promotion to stable.
- **Cleaner package storage:** AUR builds strip debug artifacts automatically and enforce a 1 GiB cache ceiling, reclaiming over 8 GB of disk space.
