- **Its own session:** Kuwai logs in as its own Hyprland session with its config in `~/.config/kuwai/hypr`, so the plain Hyprland session stays yours. `install.sh --uninstall` puts back everything it replaced.
- **The island:** Agents (kitty panes and T3 Code threads), the one waiting on you, usage limits per account, system news and minimized windows, all from one notch that works from the keyboard. Allow or Deny goes through the agent's own hook.
- **Standalone Look engine:** Atomic palette switching with WCAG contrast checks, custom templates, user hooks and 13 bundled themes.
- **Zero token drift:** Every size, duration and colour in the shell comes from one shared token table, checked before every promote.
- **Automated visual checks:** Every panel is rendered in every state at standard and large text before a release reaches stable.
- **Updates you can undo:** `kuwai update-self` follows release tags, runs migrations and keeps a rollback target. `kuwai version` says what you run.
